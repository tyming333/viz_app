# 属性标注工具

属性标注已合并到主标注工具。打开根目录的 `index.html`，点击顶部“属性标注”展开画布右侧的属性面板。关闭按钮可收起面板，配置和标注数据保留。本目录仅存放属性功能模块；原 `attribute-annotator/index.html` 会跳转到主工具并自动展开属性面板。

首次开启属性标注先确认属性选择表，默认填入螺母标注的十个词条。配置分两列：左侧属性词条，右侧可选状态（顿号、中文或英文逗号、换行均可分隔）。每个词条单选；词条名不能重复，状态名可以在不同词条之间重复。“使用螺母示例”恢复示例选择表。

配置可单独导出为 `attrs-selection-table.json`，下次通过“导入配置”复用。导出格式是词条到可选状态数组的键值映射；也兼容导入上一版的 `version: 1, groups` 配置。

```json
{
  "螺母数量": ["明确可辨", "存疑", "不可辨"],
  "螺母轮廓及棱角": ["清晰", "基本可辨", "不可辨"],
  "螺杆轮廓": ["清晰", "基本可辨", "不可辨"]
}
```

按原工具的方式导入标准 JSON 并设置图片 prefix。工作区左侧看图、右侧点击状态；切图自动选中第一个符合标签筛选的框，多框图片可通过“当前标注框”、图上点击或 Objects 列表切换。选择状态可直接操作；移动或修改框需要开启“编辑”。

结果直接保存到 object 的 `attrs` 键值对象：键是属性词条，值是选中状态。属性状态与框标注共用数据、撤销记录和 JSON 导出。

```json
{
  "example.jpg": {
    "width": 640,
    "height": 182,
    "det": {
      "objects": [
        {
          "labels": ["正常无遮挡螺母"],
          "bbox": [56, 102, 90, 102, 90, 174, 56, 174],
          "attrs": {
            "螺母数量": "明确可辨",
            "螺母轮廓及棱角": "清晰",
            "螺杆轮廓": "清晰"
          }
        }
      ]
    }
  }
}
```

选择新状态只更新对应词条；“清空该项”只删除对应键。配置之外的已有词条保留，配置中已删除的旧状态也保留并提示，直到选择新状态。保留 `attrs` 中现有的 `box_type` 以及数字、对象等其他元数据。导入时自动把有效的旧 `score_attrs` 合并到 `attrs` 并删除旧字段；同名字段优先保留现有 `attrs`。旧 `score_attrs` 若不是词条到非空状态文本的对象（包括上一版数组），会保留原数据并提示核对，停止该框的属性写入。新标注不再增加 `score_attrs`。

属性修改支持“撤销上一步”或 Ctrl+Z；切图保留配置和标注结果。批量预览期间停止状态写入。点击顶部“导出 JSON”保存全部修改；“选择导出”沿用原工具导出勾选图片和标准 JSON 的功能。属性配置单独导出。

```powershell
node --test tests/*.test.js yolo-viewer/tests/*.test.js attribute-annotator/tests/*.test.js
node attribute-annotator/tests/browser-smoke.cjs <截图输出目录>
```

浏览器测试支持设置 `ATTRS_TEST_FILE_URL=1` 验证直接打开 HTML，默认通过本地 HTTP 验证 Worker 导入。
