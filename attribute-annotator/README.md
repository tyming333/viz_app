# 属性标注工具

属性标注已合并到主标注工具。打开根目录的 `index.html`，点击顶部“属性标注”展开画布右侧的属性面板。关闭按钮可收起面板，配置和标注数据保留。本目录仅存放属性功能模块；原 `attribute-annotator/index.html` 会跳转到主工具并自动展开属性面板。

首次开启属性标注时导入属性 JSON。配置只通过 JSON 文件导入，不提供页面内编辑或内置默认表；导入的新文件会替换当前配置。示例文件：[attrs-selection-table.example.json](./attrs-selection-table.example.json)。

每个属性词条对应一个状态数组，属性名不能重复，状态名可以在不同属性之间重复。导入也兼容上一版的 `version: 1, groups` 配置。

```json
{
  "螺母数量": ["明确可辨", "存疑", "不可辨"],
  "螺母轮廓及棱角": ["清晰", "基本可辨", "不可辨"],
  "螺杆轮廓": ["清晰", "基本可辨", "不可辨"]
}
```

按原工具的方式导入标准 JSON 并设置图片 prefix。工作区左侧看图、右侧点击状态；切图自动选中第一个符合标签筛选的框，多框图片可通过图上点击或 Objects 列表切换。选择状态可直接操作；移动或修改框需要开启“编辑”。

结果直接保存到 object 的 `attrs` 键值对象：键是属性词条，值是选中状态。属性状态与框标注共用数据、撤销记录和 JSON 导出。

```json
{
  "example.jpg": {
    "width": 640,
    "height": 182,
    "det": {
      "objects": [
        {
          "labels": ["正常无遮挡螺母"],
          "bbox": [56, 102, 90, 102, 90, 174, 56, 174],
          "attrs": {
            "螺母数量": "明确可辨",
            "螺母轮廓及棱角": "清晰",
            "螺杆轮廓": "清晰"
          }
        }
      ]
    }
  }
}
```

选择新状态只更新对应词条；“清空该项”只删除对应键。配置之外的已有词条保留，配置中已删除的旧状态也保留并提示，直到选择新状态。保留 `attrs` 中现有的 `box_type` 以及数字、对象等其他元数据。

属性修改支持 Ctrl+Z 撤销。工作内容自动保存在当前浏览器本机，刷新当前页面后恢复标注 JSON、属性配置、图片路径前缀、当前图片、当前框、筛选条件、缩放位置和显示开关；新打开页面不会载入之前的工作，新导入的 JSON 替换当前工作内容。保存状态显示在左侧导入区域，保存失败时提示导出 JSON。自动保存只在当前浏览器和机器有效，跨机器使用时需导出并导入 JSON。批量预览期间停止状态写入。点击顶部“导出 JSON”保存全部修改；“选择导出”沿用原工具导出勾选图片和标准 JSON 的功能。

属性面板使用紧凑两列布局，顶部只显示属性状态、完成数量和属性配置。通过画布或右侧 Objects 列表选择标注框。导入包含已有属性的 JSON 时，弹出一次性“校验并复用已有属性标注”选择窗口：勾选时按属性配置校验全部框，允许只包含部分属性；未导入配置时可在窗口中导入配置，或取消勾选后直接导入。窗口显示通过的框数和属性数，并列出格式错误、无效状态及配置外的文本字段。配置外字段保留但不作为属性复用，`box_type`、数字及对象等元数据保留。校验不修改原始数据，取消导入保留当前工作内容。刷新恢复本地草稿不再弹出导入选择窗口。

```powershell
node --test tests/*.test.js yolo-viewer/tests/*.test.js attribute-annotator/tests/*.test.js
node attribute-annotator/tests/browser-smoke.cjs <截图输出目录>
```

浏览器测试支持设置 `ATTRS_TEST_FILE_URL=1` 验证直接打开 HTML，默认通过本地 HTTP 验证 Worker 导入。
