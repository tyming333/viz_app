# 主查看页字体设计规范

更新日期：2026-09-22。本文是主查看页后续新增、修改 UI 时的字体设计基线，不只是本次调整的记录。

## 1. 目标与范围

- 同一类文字采用相同字号，通过标题、正文、辅助信息三档建立层级，避免逐个控件随意调字号。
- 保持工具型界面的紧凑布局，优先为图片画布和列表保留空间。
- 适用于根目录 `index.html` 与 `styles.css` 管理的主查看页，包括导入、筛选、图片列表、工具栏、Objects 列表、编辑区和图片状态信息。
- `field-defect/` 现场缺陷子页面不在本次统一范围内，不得为了主查看页调整而直接改变其字体。
- 画布内标注文字与翻页箭头是明确例外，见第 5 节。

## 2. 字体、字号与字重

统一字体栈：`"Microsoft YaHei", "Segoe UI", Arial, sans-serif`。按钮、输入框、下拉框、文本编辑框继承页面字体；labels 编辑内容不再单独使用等宽字体。

| 层级 | CSS 变量 | 字号 | 默认字重 | 用途 |
| --- | --- | --- | --- | --- |
| 标题 | `--font-title` | 14px | 600 | 应用名称、图片 / Objects / 编辑分区标题、空状态主标题 |
| 正文 | `--font-body` | 12px | 400 | 按钮、输入框、菜单选项、列表、编辑内容、常规字段说明 |
| 辅助 | `--font-meta` | 11px | 400 | 版本、数量徽标、进度、状态提示、图片信息及缩略图说明 |

字号变量集中定义在 `styles.css` 的 `:root`，页面 `body` 使用正文档作为基准。后续样式应引用变量，不新增零散的 `font-size: 9px/10px/13px` 或第四档普通文字字号。

正文中的关键数值允许局部采用 600 字重，例如外接矩形宽高，但不能因此放大字号。不要把整排按钮或所有字段说明都加粗。

## 3. 组件映射

| 区域 | 标题 / 正文 | 辅助信息 |
| --- | --- | --- |
| 顶栏 | 应用选择框 14px / 600；复制、导出按钮 12px | 版本文字 11px |
| 导入区 | prefix、文件选择、文件名和字段说明 12px | 加载状态与进度说明 11px |
| 筛选区 | 输入框、labels 触发按钮、候选项、已选标签及操作按钮均为 12px | 范围字段说明、尺寸统计、结果数与空候选提示 11px |
| 图片与 Objects 列表 | 分区标题 14px / 600；每条列表文字及对象操作按钮 12px | 数量徽标 11px |
| 画布工具栏 | 按钮、批量数量输入、图片名及图像调整名称 12px | 当前图片字段说明、滑块数值 11px |
| 编辑区 | 分区标题 14px / 600；labels、坐标、关键点输入及操作按钮 12px | 选中状态徽标、无关键点提示 11px |
| 画布界面信息 | 空状态主标题 14px / 600；说明文字 12px | 图片信息水印、批量缩略图说明、加载失败提示 11px |

特别注意：labels 筛选输入、下拉菜单和已选标签必须保持同档，不能让菜单选项退回浏览器默认字号。辅助容器内的按钮、输入框应显式使用正文档，避免继承成 11px。

## 4. 颜色、行高与空间约束

普通文字使用 `--text`，辅助信息使用 `--muted`；主要通过字重和颜色强化层级，而不是继续增加字号。画布深色背景上的信息保留现有浅色文字和背景遮罩，不套用白色面板的辅助文字色。

| 场景 | 当前行高 / 尺寸约束 | 维护要求 |
| --- | --- | --- |
| 页面正文 | 行高 1.4 | 作为默认基准 |
| 普通按钮、单行输入 | 行高 1.25 | 同类控件保持一致，不能裁切中文或数字 |
| 多行编辑框 | 行高 1.45 | 保持可读和可编辑 |
| 图片列表 | 虚拟步长 27px；按钮高 23px、行高 21px | 不因统一字体而改变滚动定位 |
| Objects 列表 | 虚拟步长 19px；按钮高 17px、行高 15px | 保留紧凑密度，检查 12px 文字垂直裁切 |
| 图片状态水印 | 行高 1.4 | 允许信息换行，不遮挡操作控件 |
| 批量缩略图说明 | 行高 1.2 | 保留省略与密集模式的现有行为 |

列表步长同时存在于 `app.js` 的 `createVirtualList` 调用与 CSS 布局中。若未来确需改变行高，必须协调修改两处并验证滚动；不能只改 CSS 后宣称完成。

长文件名和长 label 优先使用现有省略、悬停完整信息及菜单宽度规则，不通过缩小字号解决。窗口变窄时优先遵循现有换行和响应式布局，不能把普通文字降为 9px 或 10px。

## 5. 明确例外与隔离边界

1. **画布标注**：由 `app.js` 的标注字号状态、绘制逻辑和现有字号滑块控制，默认 13px；它表达图片内的标注，不属于三档 UI 文字。不得用页面字号变量替代其缩放换算。关键点和批量预览标注继续沿用原有绘制规则。
2. **翻页箭头**：`.image-nav` 的 30px 是图形符号尺寸，不是新增的正文层级。不要把箭头缩成 12px。
3. **共享应用选择框**：`shared/app-switcher.css` 仍有共享默认值，主查看页通过自身 `#appSwitcher` 明确覆盖为 14px / 600。不要直接修改共享样式来统一主页面，避免连带影响现场缺陷应用。
4. **现场缺陷应用**：若以后需要统一，应单独确认其页面标题、统计数值、弹窗等层级，再设计迁移方案；本文不代表该应用已经完成统一。

## 6. 后续开发规则

1. 开始新增或调整主查看页控件前，先对照本文选择标题、正文或辅助角色。
2. 优先复用现有组件样式；需要指定字号时引用对应变量，不新增孤立数值或临时覆盖。
3. 字号、字重、颜色、行高一起检查；不要只让一个按钮变小以适配宽度。
4. 维护本文和 `styles.css` 的一致性。若三档数值、组件归属、共享边界或例外发生变化，必须同步更新本文及 `tests/typography.test.js`。
5. 每次用户可见的字体变化在根目录 `CHANGELOG.md` 留下记录；不能只写变更记录而遗漏长期设计规范。
6. 本文与实现不一致时先核实原因，不以过期文档覆盖已确认的新需求；经确认的设计变更应同时落实到代码、文档和测试。

- [ ] 使用中文、英文、数字及长名称检查显示，辅助信息不会抢过正文与标题。
- [ ] 在 1440、1180、1100 宽度下检查工具栏换行、筛选行、右侧操作按钮与 Objects 文字裁切。
- [ ] 导入测试数据后检查图片 / Objects 列表、展开的下拉菜单、选中编辑状态及批量预览。
- [ ] 若改变列表尺寸，验证首尾滚动、选中定位和虚拟列表渲染一致；仅测试静态截图不够。
- [ ] 标注字号滑块、画布缩放、筛选和编辑行为保持原样；现场缺陷子页面不受主页面样式影响。
- [ ] 字体回归测试、相关现有测试和差异空白检查通过。
- [ ] 本文与变更记录同步更新，说明实际验证范围和未验证项目。
